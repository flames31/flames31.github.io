# flames31.github.io

Personal site. Plain HTML, CSS and ~30 lines of JS — no build step, no dependencies.

Served by GitHub Pages from `main` at the repo root, so pushing is deploying.

## Editing

- `index.html` — all content. Placeholders are in `[BRACKETS]`.
- `style.css` — design tokens live at the top; change `--accent` to recolor the whole site.
- `theme.js` — dark/light toggle only.

## Local preview

```sh
python3 -m http.server 8000   # then open http://localhost:8000
```
