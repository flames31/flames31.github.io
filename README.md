# flames31.github.io

Personal site. Vite + React + Tailwind, with components from [shadcn/ui](https://ui.shadcn.com).

Pushing to `main` deploys: `.github/workflows/deploy.yml` builds `dist/` and publishes it to
GitHub Pages (Settings → Pages → Source must be "GitHub Actions"). It also rebuilds daily, which
refreshes the GitHub contributions heatmap.

## Editing

- `src/data.ts` — all content: profile, about text, the "currently building" project, projects
  (and the write-ups their dialogs show), jobs, and an optional public email. Placeholders are in `[BRACKETS]`.
- `src/pages/` — one file per page. Adding a page means a route in `src/main.tsx` and an entry
  in `src/routes.ts` (the build uses that list to write each page its own `index.html`).
- `scripts/contributions.mjs` — fetches the heatmap data into `src/generated/` before every build/dev run.
- `src/icons.ts` — tech logos (Simple Icons paths + brand colors). Add one here to use it in a `stack`.
- `src/index.css` — design tokens live at the top; change `--primary` in `:root` / `.dark` to recolor the site.
  The `[data-palette]` blocks below them are the alternative palettes visitors can switch to; the list of
  names is in `src/components/palette.tsx`.
- `src/components/ui/` — shadcn components, generated by `npx shadcn@latest add <name>` and safe to edit.

## Local

```sh
npm install
npm run dev       # http://localhost:5173
npm run build     # type-check + production build into dist/
npm run preview   # serve dist/
```
